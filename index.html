How function composition works

Composition feeds the output of one function into another. Written (f∘g)(x) = f(g(x)), it means: apply g first, then f.

A worked example

Let f(x) = x² + 1 and g(x) = 2x − 3. To find f(g(x)), replace every x in f with g(x): (2x − 3)² + 1. To find g(f(x)), do the reverse: 2(x² + 1) − 3 = 2x² − 1. The two answers differ, so order matters.

Domain

f(g(x)) exists only when g(x) is defined and its output is allowed by f. If f(x) = √x and g(x) = x − 4, then f(g(x)) needs x − 4 ≥ 0, so x ≥ 4. The graph page shows gaps where a composite is undefined.

Inverse functions

If f and g undo each other, both f(g(x)) and g(f(x)) simplify to x. Try f(x) = 2x + 3 with g(x) = (x − 3)/2 on the Examples page.

Decomposing a function

To split h(x) = (3x + 1)⁴ into two functions, name the inside g(x) = 3x + 1 and the outside f(x) = x⁴. Then h = f∘g. This is the first step of the chain rule in calculus.

Questions

Why does the result say undefined?

The input broke a rule of a function, such as dividing by zero, taking the square root of a negative number, or taking the log of zero or less.

Does Composer simplify the result?

No. It shows the substituted form exactly, so you can see each step. The table and graph confirm the values numerically.

Are my functions saved?

Yes, in this browser only, so they are still here when you return.

Can I use degrees?

Trig functions use radians. For degrees, write sin(x*pi/180).

Composer runs entirely in your browser. Nothing you type is sent anywhere.
